Подключение к OpenCode, Cursor и VS Code

GIGAMOGG работает как локальный и сетевой OpenAI-сервер. Вставьте эти настройки в вашу среду разработки.

API: http://127.0.0.1:8000/v1
~/.continue/config.json 
{
  "models": [
    {
      "title": "GIGAMOGG",
      "provider": "openai",
      "model": "gigamogg",
      "apiBase": "http://127.0.0.1:8000/v1",
      "apiKey": "gm_live_ваш_ключ"
    }
  ]
}
CURSOR SETTINGS (CUSTOM OPENAI) 
1. Откройте Cursor Settings -> Models -> OpenAI API Key:
   Вставьте: gm_live_ваш_ключ
2. Override OpenAI Base URL:
   Вставьте: http://127.0.0.1:8000/v1
3. Model Name:
   Добавьте модель: gigamogg
CLINE / ROO CODE SETTINGS 
API Provider: OpenAI Compatible
Base URL: http://127.0.0.1:8000/v1
API Key: gm_live_ваш_ключ
Model ID: gigamogg

Быстрый старт подключения (Интеграция)

PYTHON (OPENAI SDK) 
from openai import OpenAI

# Подключение к локальному серверу GIGAMOGG
client = OpenAI(
    base_url="http://127.0.0.1:8000/v1",
    api_key="gm_live_ваш_ключ"  # Скопируйте ключ выше
)

response = client.chat.completions.create(
    model="apex",
    messages=[
        {"role": "user", "content": "Напиши игру 'Змейка' на Python"}
    ],
    temperature=0.7
)

print(response.choices[0].message.content)
CURL (BASH / POWERSHELL) 
curl http://127.0.0.1:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer gm_live_ваш_ключ" \
  -d '{
    "model": "apex",
    "messages": [{"role": "user", "content": "Привет, GIGAMOGG!"}],
    "temperature": 0.8
  }'
JAVASCRIPT (FETCH) 
const res = await fetch("http://127.0.0.1:8000/v1/chat/completions", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer gm_live_ваш_ключ"
  },
  body: JSON.stringify({
    model: "apex",
    messages: [{ role: "user", content: "Объясни квантовые вычисления" }]
  })
});
const data = await res.json();
console.log(data.choices[0].message.content);
